A tiny program that writes one line of horror to a text file. The line is a
single sentence of at most 200 characters: a fitness tracker logs steps taken
while its owner is asleep in bed, and the route it recorded ends at the
bedroom door.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory). Running it twice produces byte-identical output.
